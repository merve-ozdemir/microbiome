# Gut microbiomes across urbanization levels in four African countries 

Autumn 2026 Applied Bioinformatics course project. We analyse shotgun metagenomes from 53 people in Cameroon, Tanzania, Madagascar and Guinea-Bissau, sampled at four urbanization levels (Urban, Peri-urban, Peri-rural, Rural), to investigate how the gut microbiome differs across urbanization levels, accounting for factors such as host age. 

## Layout

Folder Contents:

`notebooks/` | One Jupyter notebook per step, numbered in run order 
`scripts/` | Slurm job scripts and Python modules used by the notebooks 
`data/` | Links to the raw data in scratch, not included here 
`results/` | Tables and figures for our report, not included here 
`logs/` | Slurm job logs, not included here 

Large files (`.qza`, `.qzv`, FASTQ, BAM) are excluded by `.gitignore`.
